# Component catalog

Reusable UI only. Routed pages stay in the app and are not catalog entries.

| Name | Framework | Status | Purpose |
| --- | --- | --- | --- |
| [HasPermission](angular/HasPermission.md) | Angular | stable | Shows an action only when the signed-in user has a permission code. |
| [FeedbackBanner](angular/FeedbackBanner.md) | Angular | stable | Shows success (`role="status"`) and error (`role="alert"`) notices from one service. |
| [ConfirmDialog](angular/ConfirmDialog.md) | Angular | stable | Asks before stop, rollback, delete secret, disable user, and prepare edge. |
| [Button](angular/Button.md) | Angular | stable | Material button pattern for primary, secondary, danger, and busy actions. |
| [TextField](angular/TextField.md) | Angular | stable | Outline text, number, password, and multiline fields with a hint and error. |
| [SelectField](angular/SelectField.md) | Angular | stable | Outline select whose options are data, with a hint and error. |
| [CheckboxField](angular/CheckboxField.md) | Angular | stable | Checkbox whose hit target includes the label. |
| [RecordList](angular/RecordList.md) | Angular | stable | Bordered list of records with title, meta, status, and actions. |
| [StatusBadge](angular/StatusBadge.md) | Angular | stable | Deploy status label, or a short text chip. |
| [ActionCluster](angular/ActionCluster.md) | Angular | stable | Named group of actions on one record. |
| [PageState](angular/PageState.md) | Angular | stable | First-load, error, and empty sentences. |
| [SectionBlock](angular/SectionBlock.md) | Angular | stable | Card section with one heading. |
